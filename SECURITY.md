# Politique de sécurité

Ce dépôt contient des exemples d'infrastructure, pas un service hébergé.

Pour signaler une vulnérabilité dans les scripts ou configurations, ouvrez une alerte de sécurité privée GitHub si cette fonctionnalité est activée. Ne publiez jamais de secrets, d'adresses privées réelles, de dumps ou de journaux non nettoyés.

Les vulnérabilités propres à Vaultwarden, MariaDB, Caddy, Docker ou WireGuard doivent également être signalées aux projets concernés selon leurs politiques respectives.
