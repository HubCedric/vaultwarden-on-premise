# Contribuer

Ce dépôt est d’abord un référentiel personnel et une vitrine technique. Les corrections documentaires peuvent être proposées sans données réelles d’infrastructure.

Toute contribution doit :

- rester entièrement en français ;
- préserver les noms internes et IP WireGuard documentés ;
- ne jamais réintroduire d’adresse publique, de domaine réel ou de secret ;
- distinguer explicitement l’état actuellement déployé et l’état cible lorsqu’ils diffèrent ;
- inclure un rollback et des validations pour toute procédure opérationnelle ;
- mettre à jour le sommaire racine si une page est ajoutée ou déplacée.

Les changements touchant MariaDB, la réplication, les sauvegardes ou le safety-stop doivent être testés hors production avant intégration.
